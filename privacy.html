VITAL-SYNC

隱私權政策

最後更新：2026 年 9 月 11 日

VITAL-SYNC（以下稱「本服務」）是記錄血壓與體重的網頁應用程式。你輸入的紀錄直接存進你自己 Google 雲端硬碟裡的試算表。本服務沒有自己的伺服器，也不會收到或保存你的紀錄。

1. 從 Google 取得的資料

  • Google 帳號的名稱、電子郵件地址、大頭貼：只用來在畫面上顯示目前登入的帳號。
  • Google 雲端硬碟的檔案存取權（drive.file）：這項權限只能存取本服務自己建立的檔案，看不到你雲端硬碟裡的其他檔案。本服務用它來：
    • 找到或建立名為「VITAL-SYNC」的試算表
    • 把你新增的血壓、心跳、體重紀錄與備註寫進試算表
    • 讀取最近的紀錄，顯示在歷史紀錄畫面
    • 刪除你在畫面上指定刪除的紀錄

2. 資料存放在哪裡

  • 你的健康紀錄（時間、收縮壓、舒張壓、心跳、體重、備註）：只存在你自己的 Google 試算表，由 Google 保管。
  • 你的瀏覽器：為了重新整理後不必再登入一次，會在瀏覽器的本機儲存空間（localStorage）保存帳號名稱、電子郵件、大頭貼網址、存取權杖（最長一小時後失效）與試算表的 ID。按「登出」就會清除。
  • 離線快取：瀏覽器會暫存本網站的程式與圖示檔，讓網站在沒有網路時也能開啟。快取裡沒有你的紀錄。

3. 資料的使用與分享

本服務不會販售、出租、分享或轉移你的資料給任何人，也沒有廣告或使用行為追蹤。從 Google 取得的資料只用在上面第 1 點列出的功能。

本服務會用到以下第三方服務，它們依各自的隱私權政策處理連線資料：

  • Google：登入、試算表、雲端硬碟、網頁字型（Google 隱私權政策）
  • GitHub Pages：網站主機，可能記錄連線的 IP 位址（GitHub 隱私權聲明）

4. Google API 使用聲明

VITAL-SYNC 使用及傳輸從 Google API 取得的資訊時，會遵守 Google API 服務使用者資料政策，包括其中的有限使用（Limited Use）規定。

5. 刪除資料與撤銷授權

  • 刪除單筆紀錄：在歷史紀錄畫面按刪除，或直接在試算表裡刪掉那一列。
  • 刪除全部紀錄：到 Google 雲端硬碟刪除「VITAL-SYNC」試算表。
  • 撤銷本服務的存取權：到 Google 帳戶的第三方連結 移除 VITAL-SYNC。
  • 清除瀏覽器裡的資料：在本服務按「登出」。

6. 政策變更

本政策如有修改，會更新這個頁面與上方的「最後更新」日期。
